一、实验设计
------------------------------------------------------------------------------------------
本消融实验采用累积式设计，从纯基线模型开始，逐步添加各功能模块，
验证每个模块对最终性能的独立贡献。

  Exp0: ViT+MoCo (纯baseline)                          <- 基线
  Exp1: + 多尺度特征融合                                 <- 新增模块
  Exp2: + CutPaste合成异常增强                           <- 新增模块
  Exp3: + 超球面约束损失 (CFA)                           <- 新增模块
  Exp4: + 特征生成-判别框架 (SimpleNet)                   <- 新增模块
  Exp5: + 记忆库辅助检测 (PatchCore风格) = 完整版         <- 新增模块

四、Exp0基线模型分析
------------------------------------------------------------------------------------------
  - AUROC = 0.6749: 基线有一定区分能力，但距离理想值(>0.9)差距较大
  - F1 = 0.0952: 非常低，说明仅靠马氏距离检测效果有限
  - Accuracy = 0.9183: 看似较高，但受样本不平衡影响(正常>>异常)
  - FNR = 0.7857: 漏检率极高！14个异常样本中漏检11个，仅检出3个
  - FPR = 0.0711: 误检率尚可，928个正常样本中误检66个
  - 最佳阈值 = 7.5363: 阈值偏高，说明特征空间中正常/异常分布重叠严重

  关键问题: 基线模型对异常的召回能力极差(FNR=78.57%)，
  需要通过多尺度融合、合成异常、超球面约束等模块显著改善。
